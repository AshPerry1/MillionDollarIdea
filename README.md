# SIGNAL — Million Dollar Idea

**The idea:** A website that’s worth visiting because it *is* the experience — not a page *about* money. It reads passive visit data (location, time, device, browser, connection) and turns you into a unique character in a 60-second rhythm game.

**Live:** [ashperry1.github.io/MillionDollarIdea](https://ashperry1.github.io/MillionDollarIdea/)

## Flow

1. **Scan** — animated read of what your browser already reveals  
2. **Reveal** — your archetype, glyph, and Signal ID  
3. **Lock On** — timing game tuned to your personal beat window  
4. **Share** — score + archetype card  

Push to `main` → GitHub Pages deploys automatically.
